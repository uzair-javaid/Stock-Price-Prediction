# 📈 Stock Price Prediction using Simple Linear Regression

This project predicts future stock prices using **Simple Linear Regression**. It takes the number of days as input and predicts the corresponding stock price based on historical data.

---

## 🧠 Overview

The goal of this project is to build a simple machine learning model that learns the relationship between **Days** and **Stock Prices** from past data. The model can then be used to forecast future stock prices.

---

## 📂 Dataset

The dataset used in this project is a CSV file named **`stock_prices.csv`** that contains two columns:

| Column | Description                      |
| ------ | -------------------------------- |
| Day    | Day number (1, 2, 3, …)          |
| Price  | Closing stock price for that day |

Example:

```
Day,Price
1,100
2,102
3,105
...
```
